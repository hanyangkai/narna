# Public Skills Hub index

Sample index for `narna skills hub-sync` / `POST /v1/agent/skills/hub/sync`.

```bash
# From a clone
narna skills hub-sync --url skills/public-index.json

# Or set env
export UAP_SKILL_HUB_INDEX_URL="https://raw.githubusercontent.com/hanyangkai/narna/main/skills/public-index.json"
narna skills hub-sync
```

Not a Nous Portal clone — plain JSON anyone can host.
