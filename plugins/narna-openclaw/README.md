# @narna/openclaw

OpenClaw plugin scaffold for [NARNA](https://narna.org) Decision Quality (ADQA) over MCP.

```bash
# From this directory (when published):
npm install @narna/openclaw
# Or copy SKILL.md into your OpenClaw skills path
```

Configure MCP — see [SKILL.md](./SKILL.md).

**Not** a full Hermes toolbelt over MCP — ADQA + Ask + runtime status only.
