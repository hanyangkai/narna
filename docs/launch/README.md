## Quick start (today)

1. Open today's day file: `docs/launch/days/day-NN.md`
2. Do the **Must ship** block (≤60 min total across roles)
3. Copy ship log template → `docs/ship-log/YYYY-MM-DD.md`
4. Post **One-liner** to [GitHub Discussions → Ship log](https://github.com/hanyangkai/narna/discussions/categories/ship-log)
5. Tick boxes in [`SCORECARD.md`](./SCORECARD.md)
